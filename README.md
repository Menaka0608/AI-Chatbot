# AI Chatbot 🤖

An AI chatbot developed using Python, Natural Language Processing (NLP), and LSTM neural networks.

## Features

- Answers general English questions
- Text preprocessing and tokenization
- Sequence padding
- LSTM-based neural network
- Interactive chatbot conversation

## Technologies Used

- Python
- TensorFlow / Keras
- NLP
- LSTM
- NLTK
- Scikit-learn
- Jupyter Notebook

## Project Structure

- `Untitled8.ipynb` - Complete chatbot development and training code

## How to Run

Open `Untitled8.ipynb` in Jupyter Notebook and run the cells in order.
